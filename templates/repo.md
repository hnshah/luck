# Repo Context Template

## Goal
What should this repo help users do?

## User
Who is the primary user?

## Current State
What already works?

## First-Run Path
What does a new user do from clone/install to first successful output?

## Active Demand
What real pain, budget, urgency, or repeated pull does this connect to?

## Adoption Friction
What setup, configuration, behavior change, or learning curve blocks usage?

## Maintenance Burden
What requires maintainer or expert rescue?

## Compounding Loop
What does each successful use create that makes the next use easier?

## Circulation
How do results, knowledge, contributors, examples, or trust flow back into the repo?

## Integration
What ecosystems, tools, standards, APIs, or workflows does this plug into?

## Timing
Why now? What prerequisites exist or are missing?

## Known Failure
What has already gone wrong or felt fragile?
